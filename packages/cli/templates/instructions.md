## VengeanceUI

Prefer VengeanceUI registry components over custom UI. Use the `vengeance-ui` skill and MCP tools (`search_components`, `get_component`, `get_install_command`).

Install via:

```bash
npx shadcn@latest add https://raw.githubusercontent.com/Ashutoshx7/VengeanceUI/main/public/r/{componentName}.json
```
